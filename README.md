# leech's TwitchChat-Commands 2.0

This website is a custom command overview created for my Twitch community.

## What's new in 2.0
- New layout: sticky search and tabs, category sidebar, collapsible sections
- Command counter per tab and category, also while searching
- Color-coded commands (`!` commands, `#` game commands, word triggers)
- VIP / SUB badges for role-restricted commands
- Copy a command with one click (button or the command itself)
- Click the logo to return to the start view
- Moderator section is encrypted and only accessible to the moderation team
